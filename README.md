# Release Notes – Editable Entity Card `v0.1.0-beta`

We are excited to announce the initial beta release of the **Editable Entity Card** (`v0.1.0-beta`)! This release lays the foundation for customizable, interactive entity management cards designed for inline data editing and seamless UI integration.

---

## 🚀 Key Features

* **Inline Editing:** Toggle between view and edit modes directly on the entity card.
* **Field Validation:** Basic built-in schema validation for required fields, inputs, and formats.
* **Customizable Schema:** Dynamic rendering of text fields, dropdowns, dates, and toggles based on standard entity metadata definitions.
* **Action Callbacks:** Out-of-the-box support for `onSave`, `onCancel`, and `onChange` events.
